# Pre-collection observation-resolution addendum

Frozen before any new 40/50/60-digit follow-up collection. The complete
initial-record analysis has run; it demonstrates a 30-digit factoring
opportunity and still leaves the short larger prefixes unresolved. No
follow-up parameter/outcome has been observed.

The original coarse checkpoints can miss a DLP lead that arises between the
last incomplete checkpoint and SLP's terminal factor. Add at most eight
bisection steps on already retained block prefixes, inside a separate
30-wall/CPU-second, 10^11-work analysis allowance charged to the same existing
diagnostic total. Each step evaluates SLP and both frozen DLP policies. A
bracket is chosen from consecutive observed prefixes where at least one DLP
policy changes from incomplete to complete. Inspect the highest-product
policy's bracket first; its midpoint observations also cover the nested
policy. If no such bracket exists, do no refinement. This is a bounded
search for a directly verified witness, not a claim of a monotone minimum
completion time. A censored midpoint narrows no bracket and ends refinement.

Every qualifying refined prefix must independently reconstruct complete
factors and show the same-position SLP result. Use the enclosing checkpoint's
cumulative split/certification cost as a conservative charge; add every
performed analysis cost. Do not interpolate costs or useful yield. Retained
records carry their original block number. No new collection is performed.

Reserve 120 rather than 90 seconds of the existing diagnostic run allowance
for terminal analysis and this optional refinement. All workload, candidate,
split, record, capture, total time/work/storage limits and gate criteria stay
unchanged. No 30-digit gate is added from the newly examined initial captures.
No expansion is permitted after this addendum. This change makes the frozen
investment criterion observable at the available collection resolution.
