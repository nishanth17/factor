repository root. The [original command sequence](https://github.com/nishanth17/factor/blob/24ff153d26ada2ec4beeead07000d183e94fd355/v2/benchmarks/qs/c10/README.md)
preserves the frozen study procedure and its lease parameters.

Read the runner and versioned controls before execution. Replay old timings
from their pinned sources; current integration pins are separate compatibility
records. Source validation is not permission to restart or enlarge accounts.

completed groups and protected reservations. New leases do not replenish the
aggregate cap.
