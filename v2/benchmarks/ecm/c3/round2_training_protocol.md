# C3 measured stopping sequence: frozen training protocol v1

Prepared before new calibration or warmed comparison calls. This is the
finite continuation of the attribution pilot, not a rewrite of that study.
No candidate is a production default yet. The accounting candidate at
bcc7a30 also needs matched warmed evidence; profile times are excluded.

## Model and transfer boundary

Use a small offline empirical stopping model inspired by measured
cost/survival strategy generation. For each observed ladder and each of two
observable modulus bands, compare SIQS now with the next block's expected
CPU cost, weighted recovery cost on a useful split, and the failure
probability times the best later continuation. Probabilities are conditional
on the actual surviving inputs; no independent-curve assumption is needed.
A zero-yield block can be useful if it reaches a profitable later block.
Require at least twelve independent subjects in the risk set before a fitted
continuation. Repeated seeds are not additional independent subjects.

The finite ladders are wide (64 independent 2000/147396 curves), compact
(64 independent 2000/50000 curves), and deep (16 at 2000/147396 then four
independent 11000/250000 curves). Wide/compact stopping points are
0/8/16/32/64; deep uses 0/8/16/17/18/20. No mixed unobserved bounds are
synthesized. Select the lowest estimated cost, with fewer curves/name as
fixed tie breakers. Compile the result into two ordinary finite tier lists;
runtime sees only current cofactor size, the configured tiers and its existing
cumulative budget/attempt state. Hidden factors, certificates, fixture IDs,
generation labels and fitted probabilities never enter dispatch.

This is an empirical projection, with workload-prior and finite-sample risk.
A root split's measured recovery cost may change for composite children under
a truncated schedule; complete recursive validation must test that. It is not
a general Bayesian factor-size posterior or an upstream optimality claim.

## Data, assignment and allowances

Use all 57 revealed training/regression subjects, including the original
training, old revealed confirmation and the 32 exactly labelled new subjects.
Weight each kind equally within its modulus band, and each subject equally
within kind. All seeds have equal weight. This synthetic prior is declared,
not a claim about service traffic. Known smaller factors stratify data only.

Nine matched seed observations are 17,43,89,113,151,181,223,269,307. Different
seeds sample search variability, so observations include seed and process
variation. Every phase validates at least three seconds of both PyPy CPU and
wall warmup per arm in every acquired process, with a 30-second prepaid cap.
Retain cold startup separately; instrumented calibration is never acceptance
performance evidence. Actual complete calls use the frozen C1 SLP/half-base
DLP bundles, 10^13 work, 5/30 CPU/wall seconds, 288 MiB workspace, one worker,
and identical protected floors for every new-policy arm. The authentic
b3b3cfb control keeps its original allocation path and numerical schedule.

Calibration: no-ECM fallback plus the three full ladders, 57 subjects x nine
seeds x four arms = 2052 complete calls maximum. Instrument only root new-job
and completed-event boundaries to record whole-curve CPU cost and useful
first-hit position, root relation CPU and post-hit recursive CPU. Fit SIQS
cost from each matched no-ECM call; charge positive extra setup before the
first curve relative to the no-ECM relation entry. Exclude subjects solved
before ECM from the conditional fit, retaining them in complete evaluation.
A censored or incomplete calibration cannot fit a candidate. The cumulative
calibration cap is 3600 active seconds, including reacquisition warmup and
captures. Exhaustion ends this protocol without selection; do not extend it.

Commit the fitted tier table and raw-evidence hashes before complete comparison.
Comparison uses immutable integrated control, optimized fixed32 and fitted:
57 x nine x three = 1539 uninstrumented complete calls maximum, with a separate
3600-active-second cap. Rotate arm order by sample and fixture, reversing on
alternate samples. Capture validated outputs, coverage, fallback, work,
CPU/wall, workspace, RSS and checkpoint size. No local parameter refinements
are allowed in this protocol. Intermediate factors and recursive/power/smooth
regression classes stay in the objective; report class behavior separately.

Individual coordinated leases are at most 1200 active seconds. Prepay each
next full 5/30-second call plus one second capture allowance before admission;
reserve warmup too. Crash recovery charges a retained prepaid grant. Resume
only completed immutable rows with matching source/protocol/assignment.
Cumulative phase caps include all leases, warmups and interrupted attempts.
Keep the machine-wide lock and coordinate C9 between leases.

## Selection and new confirmation

Report the model's conditional probabilities/costs and compiled table, plus
matched complete CPU/wall and completion by class. A model is worth retaining
only if its actual complete calls improve on fixed32, not merely on its own
projection. Cluster uncertainty by independent input, respecting seed pairs;
use 10,000 bootstrap resamples seeded 2026101109. Commit one choice before
fresh generation. Zero correctness failures, no class completion loss above
five percentage points, and a positive 95% CPU-improvement interval against
both controls are required. Wall regressions above 5% require rejection.
If these gates fail, preserve the negative result and keep the fixed control.

Prepare a separately named confirmation freeze before generating new disjoint
subjects or timing them. Use new certified inputs covering the same exact
balanced and smaller-factor strata, new seeds, at least nine matched samples,
and predefined finite instability extensions. Neither old confirmation nor
these 57 training subjects is fresh. Confirmation cannot pick a replacement
winner. No C3 closure or dispatch promotion follows from calibration alone.
