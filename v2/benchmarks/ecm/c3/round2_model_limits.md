# C3 stopping-model interpretation

The fitted sequence is a small empirical projection, not an optimal dispatcher
or a Bayesian posterior over unknown factor sizes. It chooses one observed
prefix from three ladders. The twelve-subject risk-set floor prevents treating
many repeated seeds as many independent inputs; it is not a confidence bound.
The independent complete comparison and fresh confirmation carry the decision.

The no-ECM run supplies a matched-input/outer-seed estimate of SIQS cost.
It is not an identical relation-engine random stream: portfolio.py draws
siqs_seed from the shared generator after consuming ECM assignments. Changing
the number of curves therefore changes the later SIQS assignment. A reported
conditional probability is observed useful root-split frequency on the declared
weighted survivors, not a guarantee for the next service input. Complete calls
must account for this engine/seed coupling.

Calibration times root curves at new-job/completed-event boundaries. Arithmetic
setup happens inside advance_job and is included. Tiny dict construction and
bookkeeping between those boundaries are not all attributed to individual
curves. The positive first-entry setup difference is included in the model,
but the model is not an exact decomposition of complete CPU expense. Row CPU
and wall measurements include the whole factoring call and output validation;
only the uninstrumented comparison can establish total benefit.

After an ECM hit, calibration measures recovery using the full observed ladder.
A compiled shorter ladder also applies to recursive children, so that recovery
can change. The complete comparison keeps recursive/power/preprocessing inputs
in the objective and penalizes unresolved returns. Model predictions alone
cannot establish either speed or completion.

Training weights are the declared equal-band/equal-kind synthetic prior. The
Pocklington generator is nonuniform, including at smaller factor sizes.
The prepared uniform-candidate proof helper can reduce that particular bias
in new confirmation; larger constructed partners and product-digit rejection
still require disclosure. It does not retroactively improve training data.

Nine different training seeds sample both search variation and process noise.
Those are selection observations, not nine repeated timings of each fixed
seed. Accepted confirmation needs new independent inputs, new fixed seeds,
at least nine repetitions and finite predeclared instability extensions.
Owned workspace bounds and process high-water RSS must also remain distinct:
the captured RSS is a process high-water observation, not per-call ownership.

The implementation keeps runtime simple: the input size band selects finite
ECM tiers at call entry. Recursive children inherit that configured schedule;
this experiment does not add per-child size routing. Existing cumulative
ledger, protected fallback and resume state still govern every child.
There is no online probability fitting, factor-label lookup or fixture dispatch.
If the fitted tiers do not beat optimized fixed32 as well as historical control,
retain the fixed policy rather than paying for unsupported complexity.
