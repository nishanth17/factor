# Study reports

Committed results, bounded follow-up designs and adoption records. These
files preserve each study's source identity, resource accounting, findings
and limitations. A closed or user-directed adoption does not convert an
inconclusive experimental gate into a pass.

| Reports | Scope |
| --- | --- |
| [A1b final decision](a1b_gap_closure.md), [numerical evidence](a1b_final_results.json), [prompt audit](a1b_prompt_audit.md) | Completed existing-option review, retained defaults, preserved failures and explicit gap repair |
| [A1a frozen results](a1a_frozen_results.md), [adoption](a1a_default_promotion.md) | Collector integration, separate extension losses and scoped default choice |
| [C10a-04 preliminary result](c10a04_short_results.md), [promotion](c10a04_default_promotion.md), [65-digit spike](c10a04_spike65_results.md) | Compact larger-band evidence and routing limits |
| [C10a-07 recovery](c10a07_recovery_results.md), [source gap](c10a07_source_gap_results.md) | Retained diagnostics and sparse scheduling investigation |
| [C10a-07 assessment](c10a07_research_assessment.md), [panel](c10a07_panel_results.md), [adoption](c10a07_default_promotion.md) | Mechanism dispositions, final panel and user-directed integration |

Paired JSON files carry machine-readable summaries where supplied. Earlier
unexecuted designs and incomplete campaigns remain historical records;
their presence schedules no new run. Use [STATUS](../STATUS.md) for current
work and defaults, [benchmark results](../benchmarks/RESULTS.md) for summaries,
and [benchmark runners](../benchmarks/README.md) for reproduction.
